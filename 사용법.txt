Modore — 사용법 (한국어)
──────────────────────────────────────────────────────

■ 무엇을 하는 도구인가요?

두 가지 질문에 답하는 로컬 진단 도구입니다.

1) 내 컴퓨터가 몰래 일하고 있나?
   바이러스·원격 조종·몰래 채굴 신호, 자동실행, 네트워크 연결,
   그리고 macOS가 System Data/Developer로 뭉뚱그린 저장공간의 정체.

2) AI 도구가 무엇을 남겼나? (macOS)
   Claude·Codex·Gemini 같은 도구가 어떤 프로젝트를 만졌고,
   어떤 세션 기록이 며칠 뒤 자동 삭제되며,
   어떤 작업 사본이 세상에 하나뿐인지.

결과는 신호등(🟢🟡🔴)과 근거로 보여줍니다.
무엇도 자동으로 삭제하지 않습니다 — 모든 정리는 미리보기와 개별 승인을 거칩니다.

한국 사용자 특화: 은행·관공서 보안 플러그인(IPinside, nProtect, MagicLine 등)을
알아보고 "정상 설치물"과 "진짜 의심 신호"를 구분해 설명합니다.


■ 3분 시작

  Windows        검사하기.bat 더블클릭 → [2] 정밀 검사 → 브라우저에 결과
  macOS (앱)     Mac앱실행.command 우클릭 → "열기" → 앱에서 [지금 검사]
  macOS (터미널) 검사하기.command 우클릭 → "열기" → [1] 빠른 검사

  ※ macOS에서 "확인되지 않은 개발자" 경고가 뜨면: 우클릭 → "열기" (최초 1회만)


■ macOS — 앱으로 쓰기

  1. 공증된 DMG 배포판이면 앱을 Applications로 옮겨 바로 실행합니다.
     소스 ZIP이면 "Mac앱실행.command" 우클릭 → "열기"로 빌드합니다.
  2. 소스 모드는 매 실행 시 증분 빌드로 앱과 내장 진단 스크립트를 최신으로 맞춥니다.
  3. [지금 검사] → 요약 화면에 남은 공간과 직전 검사 이후의 변화가 표시됩니다.
  4. [왜 변했나] → 증가한 경로와 추적되지 않은 APFS/swap/임시 변화를 구분합니다.
  5. [공간 정리] → 항목 선택 후 [정리 검토]를 누르면 미리보기가 열립니다.
     대상 경로, 예상 크기, 종료해야 할 프로세스, 재다운로드 비용을 확인하고
     개별 승인해야만 실행됩니다.
  6. 설치 앱 제거는 번들 ID로 재확인한 뒤, 앱에 정확히 귀속되는 데이터만
     휴지통(~/.Trash/Modore-…)으로 이동합니다. 즉시 영구 삭제하지 않습니다.
  7. Simulator 기기는 [보존]/[보존 해제]로 관리하며, Shutdown 상태이고
     보존되지 않은 기기만 [삭제 검토]가 나타납니다.
  8. "매시간 확인"을 켜면 여유 공간 표본을 제한 개수만 기록하고
     위험할 때(20GB 미만, 또는 직전보다 8GB 이상 감소)만 알립니다.
  9. 툴바의 리포트 메뉴는 브라우저로 열거나 남에게 보여줄 때만 사용하세요.


■ macOS — AI가 남긴 것 검사하기 (터미널)

  python3 scripts/scree.py

    Claude Code / Codex / Gemini / VS Code 계열의 로컬 기록을 겹쳐서 판정합니다.
    - 어떤 도구들이 같은 프로젝트를 만졌는지 (교차 활동 그룹)
    - 어떤 세션 기록이 며칠 뒤 자동 삭제되는지 (보존 예보, D-day)
    - 사라진 프로젝트를 가리키는 고아 세션은 무엇인지
    - 에이전트 워크트리와 본체 체크아웃 중 "세상에 하나뿐인 작업"은 무엇인지
    - 세션 기록 속 작업 경로가 지금도 존재하는지, git인지, 소멸했는지 (계보)

    대화 내용은 읽어도 저장·출력하지 않습니다(메타데이터 전용).
    판정은 미리보기 수준 증거이며, 삭제를 실행하는 기능이 아닙니다.

  python3 scripts/scree.py preserve <세션파일경로>

    곧 만료되는 세션 하나를 마크다운으로 백업합니다.
    이메일·API 키·개인키·홈경로는 기본으로 가려지며(--raw로만 해제),
    한 번에 한 파일만 내보냅니다. 일괄 내보내기는 없습니다.


■ macOS — 터미널 메뉴로 쓰기

  1. "검사하기.command" 더블클릭 (또는 터미널에서 실행)
  2. 메뉴에서 숫자 입력:
     [1] 빠른 검사 (Mac Edition)
     [2] 이전 결과 다시 보기
     [3] 공유용 결과 열기
  3. 일반 리포트와 공유용 리포트가 함께 생성됩니다.

  공유용 리포트(검사결과_공유용.html)는 PC 이름, 사용자 이름, 홈 경로를
  자동으로 가립니다. 공유 전에 내용을 한 번 더 확인하세요.

  큰 Simulator/SDK 폴더 때문에 측정이 보류됐다면:
  PCH_STORAGE_DU_TIMEOUT=0 bash scripts/scanner.sh 로 정밀 측정할 수 있습니다.


■ Windows — 쓰기

  1. "검사하기.bat" 더블클릭
  2. 메뉴에서 숫자 입력:
     [1] 빠른 검사 (1분)
     [2] 정밀 검사 (6분) — 5분 CPU 관찰 포함 (추천)
  3. 검사가 끝나면 브라우저에 결과가 뜹니다.

  정밀 검사 팁: "5분간 가만히 있기"가 핵심입니다. 유튜브/게임을 끄고 기다려야
  "아무것도 안 하는데 CPU를 쓰는 범인"이 잡힙니다.

  Sysinternals 도구(선택): 첫 실행 시 다운로드 여부를 묻습니다.
  data/config.json 에서 "sysinternals": { "autoDownload": true } 로 바꾸면
  Microsoft 서명 검증 후 sigcheck·autorunsc를 자동 내려받아
  훨씬 상세한 자동실행 분석을 제공합니다.
  저장 위치: %LOCALAPPDATA%\PC건강검진\tools\


■ 리포트 읽는 법

  🟢 안전   정상입니다. 걱정하지 않아도 됩니다.
  🟡 확인   위험하진 않지만 한 번 확인해 보세요.
  🔴 위험   즉시 조치가 필요합니다.

  각 항목 옆 [구글 검색], [VirusTotal] 버튼으로 바로 조사할 수 있습니다.

  "위험"이 나왔다면:
  1. 당황하지 말고 해당 항목의 설명을 읽으세요.
  2. 프로그램 이름을 구글에 검색 — 유명 프로그램이면 오탐 가능성,
     낯선 이름이면 악성일 확률이 높습니다.
  3. VirusTotal 버튼으로 상세 조회.
  4. Windows: "바이러스 및 위협 방지" → 전체 검사
     macOS: Malwarebytes for Mac 무료판으로 2차 검사
  5. 추가 도구: Windows — Malwarebytes Free, Emsisoft Emergency Kit
              macOS — Objective-See 도구 (KnockKnock, LuLu)


■ 로컬 전용 / 보안 원칙

  - 기본 검사는 이 컴퓨터 안에서만 실행됩니다.
  - AI 연동, OpenAI/Claude/Codex API 호출, 토큰 사용은 없습니다.
  - 검사 결과를 서버로 업로드하지 않습니다.
  - VirusTotal 조회를 직접 켠 경우에만 SHA-256 해시가 외부 조회됩니다.
  - 앱은 삭제를 자동 실행하지 않습니다. 지원되는 정리는 고정된 로컬 레시피만
    사용하며 미리보기와 개별 승인을 거칩니다.
  - 관련 Codex/Claude/Chrome/Xcode/Simulator 작업이 실행 중이면 정리를 차단합니다.
  - Codex 세션 JSONL, Claude 로컬 에이전트 작업공간, SDK, Simulator 런타임에는
    정리 버튼이 아예 생기지 않습니다.
  - 정리 후에는 다시 검사하며 영수증을
    ~/Library/Application Support/Modore/cleanup-receipts/ 에 남깁니다.
  - 승인한 정리가 진행 중일 때 앱을 종료하면, 안전한 거래 경계와 영수증 처리가
    끝날 때까지 정상 종료를 기다립니다.
  - 검사별 경로 크기 이력은 최대 180개, 시간별 여유 공간 표본은 최대 336개만
    보관하며, 이력 파일은 Application Support 아래 600 권한으로 저장됩니다.
  - macOS가 Mail/Messages/Safari/앱 컨테이너를 숨기면 Full Disk Access 안내가
    표시됩니다.


■ VirusTotal 자동 조회 켜기 (선택)

  켜면: 70여 개 백신 DB로 자동 2차 검증 / 끄면: 기본 검사만 (빠름)

  1. https://www.virustotal.com 가입 (무료)
  2. 프로필 아이콘 → "API Key" 복사
  3. 다음 중 하나로 설정:
     - 권장: VT_API_KEY 환경 변수 (현재 사용자에게만)
     - 스크립트 모드: data/config.example.json → data/config.json 복사 후 편집
     - 앱(소스 빌드 포함): ~/Library/Application Support/Modore/config.json 편집
       ("enabled": true, "apiKey": "YOUR_API_KEY")
  4. 저장 후 검사 재실행

  ※ 파일 내용은 절대 보내지 않고 해시(지문)만 조회합니다.
  ※ 무료 한도: 분당 4건, 일일 500건 — 48시간 캐시로 자동 관리됩니다.


■ 폴더 구성

  modore/
  ├─ 검사하기.bat          Windows 실행
  ├─ 검사하기.command      macOS 터미널 메뉴
  ├─ Mac앱실행.command     macOS 앱 빌드+실행
  ├─ 사용법.txt            이 파일
  ├─ 검사결과.html          스크립트 모드 결과 (검사 후 생성)
  ├─ 검사결과_공유용.html   macOS 공유용 결과
  ├─ data/                 한국 프로그램 DB(whitelist), 쉬운 설명, 설정 예시
  ├─ rules/                판정 규칙(JSON)
  └─ scripts/              스캐너·리포트·정리·감시·scree(AI 세션 감사)

  실제 API 키는 배포본에 포함되지 않습니다.
  앱의 검사 결과·리포트·이력은 ~/Library/Application Support/Modore/ 아래에
  저장되며 외부로 전송되지 않습니다.


■ 자주 묻는 질문

  Q. 검사하기.bat을 눌러도 까만 창만 뜨고 끝나요.
  A. 우클릭 → "관리자 권한으로 실행"을 시도하세요.

  Q. "이 스크립트는 실행할 수 없습니다" (Windows)
  A. PowerShell을 관리자로 열고:
     Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  Q. macOS "확인되지 않은 개발자" 경고
  A. 파일 우클릭 → "열기" (최초 1회만).

  Q. 다른 컴퓨터에서도 쓸 수 있나요?
  A. 네. modore 폴더 전체를 USB로 복사하면 됩니다. 설치가 필요 없습니다.

  Q. 백신 대신 쓰면 되나요?
  A. 아니요. 이 도구는 '진단 리포터'이지 백신이 아닙니다.
     Windows는 Defender(기본) + Malwarebytes Free,
     macOS는 Gatekeeper(기본) + Malwarebytes for Mac을 함께 쓰세요.
