# AI 스킬 관리

**Currently implemented** — macOS 앱 사이드바의 **AI 스킬**에서 홈 디렉터리의 Codex, 공유 개인 스킬, Claude 스킬, Codex 시스템 스킬과 두 호스트의 플러그인 캐시를 조회합니다. 호스트·출처 필터, 이름과 경로 검색, 동명 설치 필터, 버전·SHA-256·SKILL.md 차이 비교를 제공합니다. Modore CLI가 작업본에 연결된 경우 해당 작업본의 스킬도 읽기 전용 비교 자료로 표시합니다.

파일 존재, 설정에서의 활성 여부, 호스트의 발견 응답, 현재 세션의 로드는 별도 상태입니다. 캐시 디렉터리나 원격 설치 표식만으로 특정 버전이 활성이라고 판단하지 않습니다. **Codex 발견 확인**은 설치된 app-server를 별도로 실행해 홈 범위의 `skills/list`를 조회합니다. 현재 데스크톱 세션이나 원격 플러그인 주입 상태를 재현하지 않으며, 미응답 항목을 비활성으로 판정하지 않습니다. 다시 읽기는 이 일시적인 발견 관찰을 초기화합니다.

설치를 선택하고 **백업 후 비활성화**를 누르면 영향 범위를 확인할 수 있습니다. 실행 시 원본 전체, 링크를 해석한 내용 사본, 원본 경로와 링크 문자열, 파일 무결성 정보, 관련 호스트 설정 사본을 `~/Library/Application Support/Modore/skill-backups`에 보관합니다. 이 폴더는 소유자만 접근하도록 생성합니다. 검증한 원본을 탐색 경로 밖으로 이동하고, **백업·복구**에서 기록과 오류를 확인하거나 원래 위치로 복구할 수 있습니다. 설정 사본은 복구 참고 자료이며 자동으로 덮어쓰지 않습니다.

**Design intent** — 정리는 설치 하나씩 명시적으로 실행하며 스킬 내용의 품질을 판정하지 않습니다. 기존 세션에 이미 로드된 내용, 다른 복사본, 링크 대상은 남을 수 있습니다. 플러그인 업데이트가 파일을 재생성할 수도 있습니다. 새 세션에서 상태를 확인하세요.

복구 위치가 점유되었거나 백업이 변조되었거나 외부 링크 대상이 바뀌면 덮어쓰지 않고 오류와 백업을 보존합니다. 링크 대상이 사라진 경우에도 내용 사본은 백업 폴더에 남습니다. 내부에 별도 심볼릭 링크가 있는 스킬은 현재 이동·복구를 차단합니다. 서로 다른 볼륨 사이의 이동은 실패 상태로 기록하며 원본을 보존합니다. 실행 중 앱 종료는 기존 안전 종료 절차를 따릅니다.

**Non-goals** — 프로젝트별·관리자 배포 스킬의 전체 탐색, Claude의 실행 중 세션 조회, 원격 세션 로드 조회, 호스트 설정 변경, 플러그인 전체 제거, 규칙·훅 활성화, 자동 품질 판정은 포함하지 않습니다.

**검증 자료 → 격리된 예제 열기**를 이용하면 실제 호스트의 탐색 경로 밖에 생성된 예제로 비교, 비활성화, 복구를 연습할 수 있습니다. 이 자료는 실제 스킬에 영향을 주지 않습니다.
